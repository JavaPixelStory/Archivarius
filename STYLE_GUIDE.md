# Шпаргалка по стилям «Архивариуса»

Всё оформление собрано в четырёх местах. Цвета и радиусы — в `widgets.py`,
расположение блоков — в `ui.py`, шрифт — в `fonts.py`.

После любой правки запустите `python main.py` из папки проекта, чтобы увидеть
результат. Для сборки exe — `build.bat`.

> Экран не прокручивается и окно не растягивается (900×620 фиксировано).
> Если элемент вылезет за нижнюю границу — он обрежется.

---

## 1. Отступы между блоками главного экрана

**Файл `ui.py`, строки 119–125**

```python
WINDOW_W, WINDOW_H = 900, 620
MARGIN = 24              # поля по краям экрана
HOME_GAP = 22            # промежуток между блоками главного экрана
HOME_TEXT_SIZE = 11      # кегль пояснения и подписи «Недавние папки»
SETTINGS_TITLE_GAP = 30  # расстояние «заголовок → поле» в настройках
CONTENT_X = 31
CONTENT_W = 838          # рабочая ширина
```

`HOME_GAP` управляет **всем** вертикальным ритмом главного экрана сразу.
Колонка строится по принципу `y += высота + gap`, поэтому одно число
раздвигает или сжимает все блоки одновременно.

Текущая раскладка при `HOME_GAP = 22`:

```
кнопка Настройки        y  24.. 58
                       22 px
текст-пояснение         y  80..122
                       22 px
зона перетаскивания     y 144..394
                       22 px
подпись «Недавние»      y 416..439
                        6 px   ← подпись и селект — один блок
селект «Недавние»       y 445..485
                       22 px
кнопка Навести порядок  y 507..579
```

`MARGIN` — поля по краям всех экранов. Влияет на отступ заголовков от верхнего
края и на позицию кнопки «Настройки».

`CONTENT_X` — левый край контента на экранах просмотра, настроек и журнала.

## 2. Радиусы скруглений

**Файл `widgets.py`, строки 36–40**

```python
RADIUS_BIG = 28      # крупные кнопки (высота 46 px и больше)
RADIUS_SMALL = 18    # мелкие кнопки и чипы фильтров
RADIUS_FIELD = 16    # поля ввода
RADIUS_ZONE = 26     # зона перетаскивания
```

### Как выбирается радиус кнопки

Автоматически, по высоте — порог 46 px:

| Кнопка | Высота | Радиус |
|---|---|---|
| Настройки | 34 | 18 (маленькая) |
| Выберите папку | 54 | 28 (большая) |
| Навести порядок | 72 | 28 (большая) |
| Сохранить | 52 | 28 (большая) |
| Сбросить настройки | 52 | 28 (большая) |
| Назад (в настройках) | 52 | 28 (большая) |

Чтобы задать радиус одной конкретной кнопки в обход правила — передайте
параметр `radius` в конструктор:

```python
ui_kit.RoundButton(frame, "Настройки", ..., radius=32)
```

Порог задан в `widgets.py` в методе `RoundButton.__init__`:

```python
self._radius = radius if radius is not None else (
    RADIUS_BIG if height >= 46 else RADIUS_SMALL
)
```

## 4. Отступы внутри зоны перетаскивания

**Файл `ui.py`, функция `_build_home`, строки 361–372**

```python
zone_h = 250          # высота зоны
btn_h = 54            # высота кнопки внутри зоны
inner_gap = 20        # промежуток между «Перетащите», «или» и кнопкой
hint_h, or_h = 22, 18 # высоты текстовых строк
```

Группа из трёх элементов центрируется автоматически: считается суммарная
высота `hint_h + or_h + btn_h + inner_gap * 2`, остаток делится пополам
сверху и снизу.

Текущий результат: 18 px между текстами, 19 px до кнопки, по 60 и 62 px
до краёв зоны.

Чтобы поднять группу выше — уменьшите `zone_h`. Чтобы раздвинуть элементы —
увеличьте `inner_gap`.

## 5. Экран настроек

**Файл `ui.py`, функция `_build_settings`, строки 1006–1009**

```python
field_w = 403    # ширина поля ввода
title_h = 20     # высота строки заголовка
field_h = 40     # высота поля
y = 56           # старт первого заголовка
```

Дальше по коду идут строки вида `y += field_h + 8` — это зазоры после
каждого блока. Число после плюса и есть отступ:

| Строка | Что означает |
|---|---|
| `y += field_h + 8` | от поля до подсказки под ним |
| `y += 44 + 12` | от подсказки до следующего заголовка |
| `y += len(MODES) * 28 + 8` | от радиокнопок до «Дополнительно» |

Зазор «заголовок → поле» задаётся общей константой `SETTINGS_TITLE_GAP = 30`
(см. раздел 1) — она одна для обоих полей, поэтому рассинхрона не будет.

### Кнопки внизу

```python
btn_y = 544
self._reset_btn.place(x=CONTENT_X, y=btn_y)      # x = 31
self._settings_back_btn.place(x=390, y=btn_y)
self.s_save.place(x=621, y=btn_y)
```

Правый край последней кнопки = 621 + 255 = 876, при окне 900 остаётся
24 px поля. Зазор между «Назад» и «Сохранить» = 621 − (390 + 207) = 24 px.

## 7. Шрифт

**Файл `fonts.py`, строки 16–24**

```python
FAMILY = "Roboto"
FALLBACK = "TkDefaultFont"

FILES = {
    "normal": "Roboto-Regular.ttf",
    "medium": "Roboto-Medium.ttf",
    "bold": "Roboto-SemiBold.ttf",
    "black": "Roboto-Bold.ttf",
}
```

Шрифты лежат в `assets/fonts/`. При старте они регистрируются в системе —
пользователю устанавливать ничего не нужно. Если файлов нет, приложение
работает на системном шрифте.

**Смена шрифта:** положите TTF в `assets/fonts/`, поправьте `FAMILY` и имена
в `FILES`. Проверьте, что новый шрифт содержит кириллицу — у Poppins её не
было, и русский текст подставлялся из другого шрифта.

**Кегли** задаются по месту через `ui_kit.font(размер, начертание)`:

```python
ui_kit.font(15)          # обычный
ui_kit.font(18, "bold")  # полужирный
```

Основные кегли сейчас: заголовки экранов 18, крупная кнопка 16, кнопки 11–13,
текст в полях 11, подсказки 8, пояснение на главном `HOME_TEXT_SIZE = 11`.

Лежат в `assets/icons/`, имена фиксированы — код ищет их по имени:


имя — код подхватит без правок. Если файл удалить, кнопка покажет только
текст, нарисуется векторная заглушка.

## 10. Частые задачи

**Раздвинуть все блоки на главном** — увеличьте `HOME_GAP` в `ui.py`.
Следите, чтобы кнопка внизу не ушла за 620.

**Сделать кнопки «круглее»** — увеличьте `RADIUS_BIG` и `RADIUS_SMALL`
в `widgets.py`.

**Поменять зелёный цвет** — правьте `GREEN` и `GREEN_DARK` в обоих файлах:
`widgets.py` и `ui.py`.

**Сдвинуть кнопки внизу** — меняйте `btn_y` (вертикаль) и `x=` в вызовах
`.place()` (горизонталь) в `_build_settings` и `_build_preview`.

**Убрать горизонтальный скролл в просмотре** — сумма ширин в `COLUMNS`
должна быть меньше или равна `CONTENT_W` (838).

**Проверить, что ничего не обрезалось** — запустите `python main.py`,
пройдите по всем экранам. Автоматической проверки вёрстки в проекте нет.
