# 📚 Архивариус

> **Наводит порядок в папке с файлами: раскладывает их по годам и переименовывает на основе даты создания.**

Один `.exe`, без установки. Работает офлайн, никуда не отправляет данные.

[![Версия](https://img.shields.io/badge/версия-1.4%20build%2010-2F7D32?style=flat-square)](version.py)

## 🤔 Зачем это нужно

У вас есть папка `Загрузки` или `Фото с телефона`, в которой лежат сотни файлов с именами вроде
`IMG_4823.jpg`, `23C8hcgG08k.jpg`, `korg-ax1500g-489958.jpg`. Найти что-то невозможно.

**Архивариус** превращает это в:

```
Было:                           Стало:
📁 Фото с телефона             📁 Фото с телефона
   IMG_4823.jpg          →        📁 2012
   23C8hcgG08k.jpg       →           📄 2012-11-16_16-09-52.jpg
   korg-ax1500g-489958.jpg →        📄 2012-12-24_21-00-42.jpg
   photo_2021.jpg        →        📁 2021
                                    📄 2021-05-03_09-15-00.jpg
```

Дата берётся не из имени файла, а **из самого файла**: EXIF-теги фотографий, метаданные PDF и
офисных документов, теги видео. Имя файла и дата изменения — только запасные варианты.

### 🛡️ Безопасность

| Обещание | Как выполнено |
|---|---|
| Не удаляет файлы | Только переименование и перенос |
| Не меняет содержимое | Файл не открывается на запись |
| Не перезаписывает | При совпадении имён добавляется `_1`, `_2` |
| Всё можно отменить | Каждая операция пишется в журнал, откат одной кнопкой |
| Не лезет в сеть | Ни одного сетевого запроса |

## 🚀 Быстрый старт

### Вариант 1 — готовый `.exe` (для пользователей)

1. Скачайте `Archivarius.exe` со страницы [Releases](https://github.com/JavaPixelStory/Archivarius/releases).
2. Положите в любую папку. **Рядом должна лежать папка `assets`** — без неё не будет шрифта и картинок.
3. Запустите двойным щелчком.

```
📁 Archivarius/
   ├── 📄 Archivarius.exe
   └── 📁 assets/          ← обязательно рядом с exe
```

> [!IMPORTANT]
> Установка не нужна, но папку `assets` удалять нельзя — приложение ищет в ней шрифт Roboto,
> иконки и картинки маскота.

### Вариант 2 — из исходников (для разработки)

```bash
# 1. Клонировать репозиторий
git clone https://github.com/JavaPixelStory/Archivarius.git
cd Archivarius

# 2. Создать виртуальное окружение (рекомендуется)
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux / macOS

# 3. Установить зависимости
python -m pip install -r requirements.txt

# 4. Запустить
python main.py
```

Открыть сразу нужную папку:

```bash
python main.py "C:\Photos"
```

## 📖 Как пользоваться

### 1️⃣ Выберите папку

На главном экране перетащите папку в пунктирную область или нажмите **«Выберите папку»**.
Недавние папки сохраняются в выпадающем списке.

### 2️⃣ Проверьте план

Откроется таблица: что с чем станет. Ничего ещё не изменено.

| Колонка | Что показывает |
|---|---|
| **Имя сейчас** | Текущее имя файла |
| **Имя после** | Как будет называться |
| **Папка года** | В какую подпапку попадёт |
| **Источник даты** | Откуда взята дата |
| **Статус** | К переименованию / без изменений / ошибка |

Нажмите на строку — внизу справа появится пояснение, откуда взялась дата именно у этого файла.

Фильтры сверху переключают между «все», «к переименованию», «без изменений»,
«дата недостоверна» и «ошибки».

### 3️⃣ Запустите

Кнопка **«Навести порядок!»**. Появится прогресс, его можно прервать.

### 4️⃣ Результат

Показано, сколько файлов разложено. Доступны:

- **Открыть папку** — посмотреть результат в проводнике
- **Отменить изменения** — вернуть всё как было (по журналу)
- **Повторить пропущенные** — для файлов, которые были заняты другой программой

## ⚙️ Настройки

Экран **«Настройки»** (кнопка справа сверху).

### Шаблон имени файла

По умолчанию: `{YYYY}-{MM}-{DD}_{HH}-{mm}-{ss}`

| Переменная | Значение | Пример |
|---|---|---|
| `{YYYY}` | Год, 4 цифры | `2012` |
| `{YY}` | Год, 2 цифры | `12` |
| `{MM}` | Месяц | `11` |
| `{DD}` | День | `16` |
| `{HH}` | Часы | `16` |
| `{mm}` | Минуты | `09` |
| `{ss}` | Секунды | `52` |

Можно добавлять свой текст: `{YYYY}.{MM}.{DD} отпуск` → `2012.11.16 отпуск.jpg`

### Шаблон папки года

По умолчанию: `{YYYY}` → папки `2012`, `2013`, …

Можно сделать `Архив {YYYY}` → папки `Архив 2012`, `Архив 2013`, …

### Остальное

| Настройка | Что делает |
|---|---|
| **Режим работы** | «Переименовать и разложить» или «Только отчёт, ничего не менять» |
| **Включая вложенные папки** | Обходить подпапки рекурсивно |
| **Брать дату из имени файла** | Если других дат нет — попробовать распознать в имени |
| **Пропускать системные и скрытые** | Не трогать `desktop.ini`, `thumbs.db`, `.DS_Store`, скрытые файлы |

> [!TIP]
> Перед первой серьёзной операцией включите режим **«Только отчёт»** — он покажет план,
> но ничего не изменит.

## 🔧 Устройство кода

Проект разделён по ответственности — каждый файл можно читать отдельно.

### `core.py` — мозг приложения

Ничего не знает про интерфейс. Здесь всё про файлы и даты.

```python
core.plan(folder, cfg, cancel, progress)   # построить план, ничего не меняя
core.execute(folder, plan, cfg, journal)   # выполнить план
core.rollback(journal_path)                # отменить по журналу
core.detect_date(path, stat, cfg)          # определить дату файла
core.validate_template(template)           # проверить шаблон
```

Главный принцип: **`plan()` сначала строит полный план, `execute()` потом его выполняет.**
Поэтому вы всегда видите, что произойдёт, до того как это произойдёт.

### `ui.py` — экраны

Шесть экранов, каждый в своей функции:

| Функция | Экран |
|---|---|
| `_build_home` | Главный |
| `_build_preview` | Просмотр с таблицей |
| `_build_progress` | Прогресс |
| `_build_result` | Результат |
| `_build_journal` | Журнал операций |
| `_build_settings` | Настройки |

### `widgets.py` — внешний вид

Tkinter не умеет скруглять углы, поэтому кнопки и поля рисуются на Canvas:

- `RoundButton` — кнопка со скруглением, иконкой и подсветкой при наведении
- `Field` — поле ввода на зелёной подложке
- `CheckSquare`, `RadioDot` — флажки и переключатели (рисуются через Pillow, чтобы не были пиксельными)
- `DropZone` — зона перетаскивания с пунктиром

### `settings.py` — состояние

Хранит `settings.json` рядом с приложением. Журналы — в `journal/` рядом с ним же.

## ✏️ Как вносить изменения

### Изменить внешний вид

Полная шпаргалка — в **[STYLE_GUIDE.md](STYLE_GUIDE.md)**. Коротко:

| Что | Файл | Строка |
|---|---|---|
| Цвета | `widgets.py` **и** `ui.py` | 22 и 39 |
| Радиусы кнопок | `widgets.py` | 37–40 |
| Отступы главного экрана | `ui.py` | 120 (`HOME_GAP`) |
| Отступы в настройках | `ui.py` | 122 (`SETTINGS_TITLE_GAP`) |
| Шрифт | `fonts.py` | 16 |

> [!WARNING]
> Цвета продублированы в двух файлах. Меняйте **в обоих**, иначе кнопки и текстовые метки
> будут разного цвета.

### Изменить логику определения даты

1. Откройте `core.py`, найдите `metadata_date()` (строка ~402).
2. Добавьте обработку своего формата.
3. Проверьте результат: `python check_date.py "путь\к\файлу"`.
4. Запустите тесты: `python test_core.py`.

### Изменить шаблон по умолчанию

`settings.py`, словарь `DEFAULTS` (строка 13):

```python
DEFAULTS = {
    "template": "{YYYY}-{MM}-{DD}_{HH}-{mm}-{ss}",
    "year_folder": "{YYYY}",
    ...
}
```

### Добавить иконку кнопке

1. Положите PNG 64×64 с прозрачным фоном в `assets/icons/`.
2. Назовите по шаблону `icon_что_то.png`.
3. В `ui.py` при создании кнопки укажите `icon="icon_что_то"`.

Если файла нет — нарисуется векторная заглушка, приложение не упадёт.

### Поменять шрифт

1. Положите TTF в `assets/fonts/`.
2. Откройте `fonts.py`, поправьте `FAMILY` и имена в `FILES`.
3. **Проверьте, что шрифт содержит кириллицу** — иначе русский текст подставится из другого шрифта.

## 🧪 Тесты

```bash
python test_core.py
```

```
Пройдено: 86   Провалено: 0
```

Тесты проверяют логику без интерфейса: разбор дат, шаблоны, дедупликацию имён, откат.
**Запускайте перед каждым коммитом** — они ловят регрессии за секунды.

### Диагностика конкретного файла

```bash
python check_date.py "D:\Test\1392373.jpg"
python check_date.py "D:\Test"                  # по всей папке
```

Покажет все даты-кандидаты, отметит выбранную и итоговое имя. **Ничего не меняет.**

## 📦 Сборка `.exe`

```bash
build.bat
```

Что происходит:

1. Проверка Python (нужен 3.11+)
2. Очистка `build/`, `dist/`, старого `.spec`
3. Запуск PyInstaller с `--onefile --windowed --icon assets/icon.ico`
4. Копирование `assets` в `dist/`
5. Итог: `dist\Archivarius.exe`

Если что-то пошло не так — скрипт назовёт шаг и покажет команду.

### Проблема: после сборки старая иконка

Проводник Windows кэширует значки **отдельно для каждого размера**. После пересборки мелкие
размеры могут показывать старое.

```cmd
taskkill /f /im explorer.exe
del /a /f /q "%localappdata%\IconCache.db"
del /a /f /q "%localappdata%\Microsoft\Windows\Explorer\iconcache*"
start explorer.exe
```

Проверить, что дело в кэше: скопируйте exe в новую папку — там иконка будет верной.

### Проблема: изменения не применяются

Python кэширует байт-код в `__pycache__`. Удалите и перезапустите:

```bash
clean.bat
python main.py
```

Проверка версии: в заголовке окна должна быть строка вида
`Архивариус 1.4 build 10 (2026-11-03, uniform-button-font)`.

## 🐛 Частые проблемы

<details>
<summary><b>Кнопки без иконок</b></summary>

Нет папки `assets/icons/` или файлов в ней. Скопируйте `assets` целиком рядом с exe.
Приложение работает и без иконок — рисует векторные заглушки.
</details>

<details>
<summary><b>Русский текст другим шрифтом</b></summary>

Шрифт в `assets/fonts/` не содержит кириллицы. Roboto содержит. Если меняли шрифт —
проверьте набор глифов.
</details>

<details>
<summary><b>«В этой сборке Python нет tkinter»</b></summary>

Переустановите Python с [python.org](https://python.org), отметив галочку
**«tcl/tk and IDLE»** при установке.
</details>

<details>
<summary><b>Файлы пропущены с пометкой «дата недостоверна»</b></summary>

Программа нашла дату, но она выглядит подозрительно: из будущего, 1970 год или раньше 1990.
Такие файлы не трогаются намеренно. Проверьте: `python check_date.py "путь\к\файлу"`.
</details>

<details>
<summary><b>Не могу отменить операцию</b></summary>

Откат работает через журнал в папке `journal/`. Если её удалили — откатить нельзя.
Журналы хранят последние 20 сессий, старые чистятся автоматически.
</details>

<details>
<summary><b>Файл занят другой программой</b></summary>

На экране результата нажмите **«Повторить пропущенные»** после того, как закроете программу,
которая держит файл.
</details>
