# Архивариус

Раскладывает файлы в папке по датам: переименовывает по шаблону `YYYY-MM-DD_HH-mm-ss.ext`
и создаёт подпапки по годам (`2024`, `2023`, …). Один exe, без установки.

Приложение **не удаляет файлы, не меняет их содержимое и не перезаписывает существующие**.
Любая операция отменяема кнопкой «Отменить изменения».

---

## Если изменения «не применяются»

Python кэширует байт-код в папке `__pycache__`. Если запускается старая логика —
удалите кэш и перезапустите:

```
clean.bat
python main.py
```

Проверить, какая версия работает: в заголовке окна должна быть строка вида
`Архивариус 1.1 (2026-11-03, fix-earliest-date)`. Если её нет — запущена старая копия
(другой файл, старый exe или скомпилированный кэш).

## Проверка дат без запуска интерфейса

```
python check_date.py "D:\Test\1392373.jpg"
python check_date.py "D:\Test"
```

Покажет все даты-кандидаты по файлу, отметит выбранную и итоговое имя. Ничего не меняет.

## Запуск из исходников

```
python -m pip install -r requirements.txt
python main.py
python main.py "C:\Photos"     # сразу открыть папку
```

Нужен Python 3.11+ (на Windows — с галочкой «tcl/tk and IDLE» при установке).

Проверка ядра без GUI:

```
python test_core.py
```

## Сборка в один exe

```
build.bat
```

Внутри — ровно:

```
pyinstaller --onefile --windowed --noupx --name Archivarius --icon assets\icon.ico main.py
xcopy /E /I /Y assets dist\assets
```

Готовый файл: `dist\Archivarius.exe`. Папка `assets\` копируется рядом с exe.

`--noupx` обязателен: упаковщик UPX провоцирует ложные срабатывания антивирусов.

## Маскот

Графика не генерируется кодом. Положите свои файлы строго под этими именами:

| Файл | Что это |
|---|---|
| `assets/icon.ico` | иконка приложения (256×256, multi-res) |
| `assets/mascot_idle.png` | маскот в приветственной позе, PNG с прозрачностью |
| `assets/mascot_work.png` | маскот в работе / кадр «спасибо» |
| `assets/anim_done/001.png … 060.png` | кадры финальной анимации, 24–30 fps, до 3 с |

Пока файлов нет — рисуется векторный плейсхолдер, приложение полностью работоспособно.
Анимация проигрывается один раз и не блокирует интерфейс; при системной настройке
«уменьшить движение» показывается статика.

## Настройки и данные

Всё рядом с exe: `settings.json`, `journal/*.jsonl`, `app.log`.
Если папка недоступна для записи — `%LOCALAPPDATA%\Archivarius\`.
Хранятся последние 20 журналов сессий, старые чистятся автоматически.

Режимы: `inplace` — переименовать и разложить (по умолчанию); `dry` — только отчёт,
ничего не менять.

**Копирование не используется ни в одном режиме.** Файл переименовывается и переносится
в папку своего года через `os.rename` в пределах одного тома — место на диске не удваивается,
второй копии данных не появляется.

## Ограничения и решения, принятые по умолчанию

- **Первый запуск `--onefile` медленный** (распаковка во временную папку, 2–5 с) и файл может
  ложно триггерить Defender; для распространения рекомендуется подпись кода.
- **Берётся самая ранняя дата из всех найденных.** Собираются кандидаты: метаданные файла,
  дата из имени по шаблону, время изменения, время создания. Побеждает самая ранняя
  правдоподобная (не раньше 1980 года и не позже завтрашнего дня). Причина: копирование и
  пересохранение могут только добавить более позднюю дату, но не сделать её раньше реальной.
  Посмотреть всех кандидатов можно в `collect_dates()` в `core.py`.

| Тип файла | Откуда берётся дата |
|---|---|
| JPEG, TIFF, PNG, WebP, HEIC | EXIF: `DateTimeOriginal` (36867), затем `DateTime` (306) |
| PDF | `/CreationDate`, затем `/ModDate` в Info-словаре |
| DOCX, XLSX, PPTX и прочие OOXML | `dcterms:created`, затем `dcterms:modified` в `docProps/core.xml` |
| MP4, MOV, M4V | `creation_time` из атома `mvhd` |
| Остальное | `mtime` (сохраняется при копировании), затем `ctime` |

- **HEIC без плагина `pillow-heif`** не отдаёт EXIF через Pillow — сработает следующий источник.
- **Файл, уже названный по шаблону, перепроверяется.** Если найдена более ранняя дата, он будет
  переименован заново и перенесён в правильный год.
- **Даты файла не изменяются.** `os.utime` не вызывается ни при каких условиях: приложение
  переименовывает и переносит, но не трогает ни «изменён», ни «создан». Проверяется тестом.
- **Перемещение, а не копирование.** `os.rename` работает в пределах одного тома; папки годов
  создаются внутри той же папки, поэтому перенос всегда возможен без копирования данных.
- **Симлинки и junction-и всегда пропускаются**, чтобы обход не зацикливался и не выходил за
  пределы выбранной папки.
- **Папки годов создаются только при наличии файлов за этот год.**
- Пути длиннее 260 символов обрабатываются через префикс `\\?\`; если политика ОС это запрещает,
  файл пропускается с пояснением, а не роняет пакет.
- Сетевых запросов, телеметрии и автообновлений нет.
- Интерфейс и сообщения — на русском; все строки собраны в словаре `STRINGS` в начале `ui.py`.

## Структура

```
main.py          точка входа
version.py       метка сборки (видна в заголовке окна)
check_date.py    диагностика дат по одному файлу или папке
core.py          вся логика: сканирование, даты, шаблоны, план, исполнение, откат (без tkinter)
ui.py            экраны, маскот, анимация
settings.py      settings.json, пути, логирование
test_core.py     проверка ядра на реальных файлах
assets/          иконка и арты маскота
```
