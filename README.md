# 📚 Архивариус

> **Наводит порядок в папке с файлами: раскладывает их по годам и переименовывает на основе даты создания — или раскладывает, сохраняя прежние имена.**

- Без установки.
- Работает офлайн, никуда не отправляет данные.
- Для Windows, Linux и macOS — одна кодовая база.

[![Версия](https://img.shields.io/badge/версия-2.0-2F7D32?style=flat-square)](version.py)

## ✨ Что нового в 2.0

Главное — **кроссплатформенность**. До 2.0 приложение собиралось только под Windows.

| Было (1.4) | Стало (2.0) |
| --- | --- |
| Сборка только `.exe` | `.exe`, бинарник Linux, `.app` для macOS |
| `os.name` / `sys.platform` по всему коду | Всё в одном файле `platforms.py` |
| `st_ctime` как дата создания везде | `st_birthtime` на macOS, честный `None` на Linux |
| Имена без нормализации | NFC имена — корректная работа с «й», «ё» на APFS |
| Откат данных в `%LOCALAPPDATA%` | Стандартный каталог каждой ОС |
| Сборка вручную через `build.bat` | `python build.py` + CI на три системы |
| Выпадающий список — отдельное окно | Список внутри окна: на macOS не превращается в капсулу |

## 🤔 Зачем это нужно

У вас есть папка `Загрузки` или `Фото с телефона`, в которой лежат сотни файлов с именами вроде
`IMG_4823.jpg`, `23C8hcgG08k.jpg`, `korg-ax1500g-489958.jpg`. Найти что-то невозможно.

**Архивариус** превращает это в:

```
Было:                           Стало:
📁 Фото с телефона             📁 Фото с телефона
   IMG_4823.jpg          →        📁 2012
   23C8hcgG08k.jpg       →          📄 2012-11-16_16-09-52.jpg
   korg-ax1500g-489958.jpg →        📄 2012-12-24_21-00-42.jpg
   photo_2021.jpg        →        📁 2021
                                    📄 2021-05-03_09-15-00.jpg
```

Дата берётся не из имени файла, а **из самого файла**: EXIF-теги фотографий, метаданные PDF и
офисных документов, теги видео. Имя файла и дата изменения — только запасные варианты.

### 🛡️ Безопасность

| Обещание             | Как выполнено                                         |
| -------------------- | ----------------------------------------------------- |
| Не удаляет файлы     | Только переименование и перенос                       |
| Не меняет содержимое | Файл не открывается на запись                         |
| Не перезаписывает    | При совпадении имён добавляется `_1`, `_2`            |
| Всё можно отменить   | Каждая операция пишется в журнал, откат одной кнопкой |
| Не лезет в сеть      | Ни одного сетевого запроса                            |

## 🚀 Скачать и запустить

Готовые сборки — на странице [**Releases**](https://github.com/JavaPixelStory/Archivarius/releases).
Скачайте ту, что подходит вашей системе.

| Ваша система                      | Файл                              | Что внутри                    |
| --------------------------------- | --------------------------------- | ----------------------------- |
| **Windows 10 / 11**               | `Archivarius-2.0-windows.zip`     | `Archivarius.exe` + `assets/` |
| **Linux** (x86-64)                | `Archivarius-2.0-linux.tar.gz`    | `Archivarius` + `assets/`     |
| **macOS** (Intel / Apple Silicon) | `Archivarius-2.0-macos.zip`       | `Archivarius.app`             |

### 🪟 Windows

1. Скачайте `Archivarius-2.0-windows.zip`.
2. Распакуйте в любую папку — например, `C:\Program Files\Archivarius` или на рабочий стол.
3. Запустите `Archivarius.exe` двойным щелчком.

```
📁 Archivarius/
   ├── 📄 Archivarius.exe
   └── 📁 assets/          ← обязательно рядом с exe
```

Если Windows покажет «SmartScreen защитил ваш компьютер» — нажмите
**«Подробнее»** → **«Выполнить в любом случае»**. Это происходит потому, что файл не подписан
платным сертификатом, а не потому что в нём что-то не так.

### 🐧 Linux

1. Скачайте `Archivarius-2.0-linux.tar.gz`.
2. Распакуйте:
   ```bash
   tar -xzf Archivarius-2.0-linux.tar.gz
   ```
3. Запустите:
   ```bash
   ./Archivarius
   ```

Права на запуск уже выставлены внутри архива — `chmod +x` не нужен.
Если он всё же понадобился: `chmod +x Archivarius`.

Если система не запускает файл из-за отсутствия Tk:

```bash
sudo apt install python3-tk        # Debian / Ubuntu
sudo dnf install python3-tkinter   # Fedora
sudo pacman -S tk                  # Arch
```

### 🍎 macOS

1. Скачайте `Archivarius-2.0-macos.zip`.
2. Распакуйте — получится `Archivarius.app`.
3. Перетащите его в **Программы** (Applications) или оставьте где удобно.

**Первый запуск.** Приложение не подписано сертификатом Apple, поэтому macOS его заблокирует.
Три способа открыть:

| Способ                    | Как                                                                                     |
| ------------------------- | --------------------------------------------------------------------------------------- |
| **Правый клик** (проще)   | Правый клик по `Archivarius.app` → **«Открыть»** → в диалоге снова **«Открыть»**         |
| Терминал                  | `xattr -cr /Applications/Archivarius.app` — снимает карантин, дальше обычный запуск      |
| Настройки                 | **Системные настройки** → **Конфиденциальность и безопасность** → **«Всё равно открыть»** |

> [!IMPORTANT]
> После первого успешного запуска повторять не нужно — macOS запоминает выбор.
> Ошибка «приложение повреждено» означает не поломку файла, а сработавшую защиту Gatekeeper.

### 🗂️ Папка `assets` обязательна

Во всех трёх системах рядом с программой должна лежать папка `assets` — в ней шрифт,
иконки и картинки маскота. Без неё программа запустится, но нарисует векторные заглушки
вместо иконок и системный шрифт вместо Roboto.

## 🖥️ Кроссплатформенность

Правило проекта: **ни один файл, кроме `platforms.py`, не должен знать, какая под ним ОС.**

### Что различается и как решено

| Задача                  | Windows             | Linux                        | macOS                     | Где решено                       |
| ----------------------- | ------------------- | ---------------------------- | ------------------------- | -------------------------------- |
| Открыть папку           | `os.startfile`      | `xdg-open`                   | `open`                    | `platforms.open_in_file_manager` |
| Шрифт Roboto            | `AddFontResourceExW`| `~/.local/share/fonts`       | `~/Library/Fonts`         | `fonts.py`                       |
| Дата создания файла     | `st_ctime`          | нет — `None`                 | `st_birthtime`            | `platforms.creation_time`        |
| Имена файлов            | NFC                 | NFC                          | NFD → NFC                 | `platforms.normalize_name`       |
| Исполняемые файлы       | по расширению       | по биту `+x`                 | по биту `+x`              | `platforms.executable_suffixes`  |
| Системные папки         | `Windows`, `Program Files` | `/usr`, `/etc`        | `/System`, `/Library`     | `platforms.system_dir_names`     |
| Уменьшить анимацию      | `SystemParametersInfo` | `gsettings`               | `defaults read`           | `platforms.reduce_motion`        |
| Каталог данных          | `%LOCALAPPDATA%`    | `~/.local/share`             | `~/Library/Application Support` | `settings._fallback_dir`   |
| Иконка сборки           | `.ico`              | не встраивается              | `.icns`                   | `build.py`                       |
| Формат архива           | `.zip`              | `.tar.gz` (хранит `+x`)      | `.zip` (папка `.app`)     | `build.py`                       |

### Главная тонкость: дата создания

`st_ctime` в Python означает **разное в разных системах**:

| Система         | Что такое `st_ctime`                        | Что использовать |
| --------------- | ------------------------------------------- | ---------------- |
| Windows (NTFS)  | время создания файла                        | `st_ctime`       |
| Linux           | время смены прав/владельца, **не создания** | ничего → `None`  |
| macOS           | то же, что Linux                            | `st_birthtime`   |

Если бы код брал `st_ctime` везде, то на macOS фотография, скачанная сегодня из архива
2012 года, получила бы сегодняшнюю дату и уехала в папку 2026. Поэтому
`platforms.creation_time` возвращает `None` там, где система не хранит дату создания —
**лучше не показать дату вовсе, чем положить файл в чужой год.**

### Ресурсы и состояние

`settings.json`, `journal/` и логи лежат рядом с программой — портативно.
Если папка недоступна на запись (например, `/Applications` без прав), откат идёт
в стандартный каталог данных системы:

| Система | Куда |
| --- | --- |
| Windows | `%LOCALAPPDATA%\Archivarius` |
| macOS | `~/Library/Application Support/Archivarius` |
| Linux | `$XDG_DATA_HOME/Archivarius` или `~/.local/share/Archivarius` |

## 📖 Как пользоваться

### 1️⃣ Выберите папку

На главном экране перетащите папку в пунктирную область или нажмите **«Выберите папку»**.
Недавние папки сохраняются в выпадающем списке.

> [!NOTE]
> Перетаскивание работает через `tkinterdnd2`. Если библиотеки нет — приложение не падает,
> остаётся кнопка выбора папки. На Linux нужен графический сеанс; из консоли без графики
> окно не откроется.

### 2️⃣ Проверьте план

Откроется таблица: что с чем станет. Ничего ещё не изменено.

| Колонка           | Что показывает                            |
| ----------------- | ----------------------------------------- |
| **Имя сейчас**    | Текущее имя файла                         |
| **Имя после**     | Как будет называться                      |
| **Папка года**    | В какую подпапку попадёт                  |
| **Источник даты** | Откуда взята дата                         |
| **Статус**        | К переименованию / без изменений / ошибка |

Нажмите на строку — внизу справа появится пояснение, откуда взялась дата у этого файла.

Фильтры сверху переключают между «все», «к переименованию», «без изменений»,
«дата недостоверна» и «ошибки».

### 3️⃣ Запустите

Кнопка **«Навести порядок!»**. Появится прогресс, его можно прервать.

### 4️⃣ Результат

Показано, сколько файлов разложено. Доступны:

- **Открыть папку** — проводник / Finder / файловый менеджер
- **Отменить изменения** — вернуть всё как было (по журналу)
- **Повторить пропущенные** — для файлов, которые были заняты другой программой

## ⚙️ Настройки

Экран **«Настройки»** (кнопка справа сверху).

### Шаблон имени файла

По умолчанию: `{YYYY}-{MM}-{DD}_{HH}-{mm}-{ss}`

| Переменная | Значение     | Пример |
| ---------- | ------------ | ------ |
| `{YYYY}`   | Год, 4 цифры | `2012` |
| `{YY}`     | Год, 2 цифры | `12`   |
| `{MM}`     | Месяц        | `11`   |
| `{DD}`     | День         | `16`   |
| `{HH}`     | Часы         | `16`   |
| `{mm}`     | Минуты       | `09`   |
| `{ss}`     | Секунды      | `52`   |

Можно добавлять свой текст: `{YYYY}.{MM}.{DD} отпуск` → `2012.11.16 отпуск.jpg`

### Шаблон папки года

По умолчанию: `{YYYY}` → папки `2012`, `2013`, …

Можно сделать `Архив {YYYY}` → папки `Архив 2012`, `Архив 2013`, …

Можно добавить месяц: `{YYYY}/{MM}` → `2012/11`, `2012/12`, …

### Остальное

| Настройка                           | Что делает                                                        |
| ----------------------------------- | ----------------------------------------------------------------- |
| **Режим работы**                    | «Переименовать и разложить» или «Только отчёт, ничего не менять»  |
| **Включая вложенные папки**         | Обходить подпапки рекурсивно                                      |
| **Раскладывать без переименования** | Перемещать по папкам годов, сохраняя исходные имена               |
| **Брать дату из имени файла**       | Если других дат нет — попробовать распознать в имени              |
| **Пропускать системные и скрытые**  | Не трогать `desktop.ini`, `thumbs.db`, `.DS_Store`, скрытые файлы |

> [!TIP]
> Перед первой серьёзной операцией включите режим **«Только отчёт»** — он покажет план,
> но ничего не изменит.

## 🔨 Сборка из исходников

### Запуск без сборки

```bash
git clone https://github.com/JavaPixelStory/Archivarius.git
cd Archivarius

python -m venv .venv

# Активировать
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # Linux / macOS

python -m pip install -r requirements.txt
python main.py
```

Открыть сразу нужную папку:

```bash
python main.py "C:\Photos"          # Windows
python main.py ~/Pictures           # Linux / macOS
```

### Собрать исполняемый файл

**Одна команда на всех системах:**

```bash
python build.py
```

Скрипт сам определяет систему и собирает под неё:

| Система | Результат в `dist/`                                          |
| ------- | ------------------------------------------------------------ |
| Windows | `Archivarius.exe` + `Archivarius-2.0-windows.zip`             |
| Linux   | `Archivarius` + `Archivarius-2.0-linux.tar.gz`                |
| macOS   | `Archivarius.app` + `Archivarius-2.0-macos.zip`               |

Что делает `build.py`:

1. Проверяет версию Python (нужна 3.11+)
2. Ставит зависимости из `requirements.txt` и PyInstaller
3. Чистит `build/`, `dist/`, старые `.spec`
4. Запускает PyInstaller: `--onefile --windowed --noupx`
   - на Windows берёт `assets/icon.ico`
   - на macOS берёт `assets/icon.icns` и ставит bundle identifier
   - на Linux иконка не встраивается в бинарник
5. Копирует `assets/` рядом с результатом
6. Упаковывает в архив с версией из `version.py`

> [!IMPORTANT]
> **PyInstaller не собирает под чужую систему.** exe получается только на Windows,
> `.app` — только на macOS, бинарник Linux — только на Linux. Одна машина физически
> не соберёт все три версии. Для этого нужен CI.

### Три версии сразу — GitHub Actions

Файл [`.github/workflows/build.yml`](.github/workflows/build.yml) собирает все три версии
параллельно на трёх виртуальных машинах.

**Вручную:**

1. Вкладка **Actions** в репозитории
2. Слева **«Сборка»** → справа **Run workflow** → выбрать ветку → запустить
3. Через ~5 минут внизу страницы запуска появится **Artifacts** с тремя архивами

**Автоматически при релизе:**

```bash
git tag v2.0
git push origin v2.0
```

GitHub увидит тег вида `v*`, соберёт три версии и опубликует релиз с тремя архивами.

### Проблемы при сборке

<details>
<summary><b>Windows: после пересборки старая иконка</b></summary>

Проводник кэширует значки отдельно для каждого размера.

```cmd
taskkill /f /im explorer.exe
del /a /f /q "%localappdata%\IconCache.db"
del /a /f /q "%localappdata%\Microsoft\Windows\Explorer\iconcache*"
start explorer.exe
```

Проверить, что дело в кэше: скопируйте exe в новую папку — там иконка будет верной.

</details>

<details>
<summary><b>Изменения не применяются</b></summary>

Python кэширует байт-код в `__pycache__`. Удалите и перезапустите:

```bash
rm -rf __pycache__          # Linux / macOS
rmdir /s /q __pycache__     # Windows
```

Проверка версии: в заголовке окна должна быть строка `Архивариус 2.0`.

</details>

<details>
<summary><b>macOS: «Архивариус повреждён»</b></summary>

Это Gatekeeper, а не поломка. Снимите карантин:

```bash
xattr -cr /Applications/Archivarius.app
```

</details>

<details>
<summary><b>Linux: не запускается</b></summary>

Нет Tk в системе:

```bash
sudo apt install python3-tk
```

</details>

## 🔧 Устройство кода

Проект разделён по ответственности — каждый файл можно читать отдельно.

### `core.py` — мозг приложения

Ничего не знает про интерфейс. Здесь всё про файлы и даты.

```python
core.plan(folder, cfg, cancel, progress)   # построить план, ничего не меняя
core.execute(folder, plan, cfg, journal)   # выполнить план
core.rollback(journal_path)                # отменить по журналу
core.detect_date(path, stat, cfg)          # определить дату файла
core.validate_template(template)           # проверить шаблон
```

Главный принцип: **`plan()` строит полный план, `execute()` потом его выполняет.**
Поэтому вы всегда видите, что произойдёт, до того как это произойдёт.

### `platforms.py` — единственное место про ОС

Все различия собраны здесь: открытие папки, дата создания, нормализация имён,
исполняемые расширения, системные каталоги, настройка анимации.

### `ui.py` — экраны

Шесть экранов, каждый в своей функции:

| Функция           | Экран               |
| ----------------- | ------------------- |
| `_build_home`     | Главный             |
| `_build_preview`  | Просмотр с таблицей |
| `_build_progress` | Прогресс            |
| `_build_result`   | Результат           |
| `_build_journal`  | Журнал операций     |
| `_build_settings` | Настройки           |

### `widgets.py` — внешний вид

Tkinter не умеет скруглять углы, поэтому кнопки и поля рисуются на Canvas:

- `RoundButton` — кнопка со скруглением, иконкой и подсветкой при наведении
- `Field` — поле ввода на зелёной подложке
- `RoundedSelect` — выпадающий список. Раскрывается **внутри главного окна**, а не отдельным
  окном: на macOS система сама скругляет безрамочные окна, и на высоте одного пункта
  список превращался в капсулу
- `CheckSquare`, `RadioDot` — флажки и переключатели (Pillow, чтобы не были пиксельными)
- `DropZone` — зона перетаскивания с пунктиром

### `settings.py` — состояние

Хранит `settings.json` рядом с приложением. Журналы — в `journal/` рядом с ним же.

## ✏️ Как вносить изменения

### Изменить внешний вид

Полная шпаргалка — в **[STYLE_GUIDE.md](STYLE_GUIDE.md)**. Коротко:

| Что                     | Файл                       | Строка                      |
| ----------------------- | -------------------------- | --------------------------- |
| Цвета                   | `widgets.py` **и** `ui.py` | 23–34 и 48                  |
| Радиусы                 | `widgets.py`               | 38–43                       |
| Отступы главного экрана | `ui.py`                    | 192 (`HOME_GAP`)            |
| Отступы в настройках    | `ui.py`                    | 198 (`SETTINGS_TITLE_GAP`)  |
| Радиус кнопки справки   | `ui.py`                    | 194 (`RADIUS_HELP`)         |
| Радиус селекта          | `ui.py`                    | 199 (`SELECT_RADIUS`)       |
| Шрифт                   | `fonts.py`                 | 16 (`FAMILY`), 19 (`FILES`) |

> [!WARNING]
> Цвета продублированы в двух файлах. Меняйте **в обоих**, иначе кнопки и текстовые метки
> будут разного цвета.

### Изменить логику определения даты

1. Откройте `core.py`, найдите `metadata_date()`.
2. Добавьте обработку своего формата.
3. Проверьте: `python check_date.py "путь/к/файлу"`.
4. Запустите тесты: `python test_core.py`.

### Изменить шаблон по умолчанию

`settings.py`, словарь `DEFAULTS`:

```python
DEFAULTS = {
    "template": "{YYYY}-{MM}-{DD}_{HH}-{mm}-{ss}",
    "year_folder": "{YYYY}",
    ...
}
```

### Добавить иконку кнопке

1. Положите PNG 64×64 с прозрачным фоном в `assets/icons/`.
2. Назовите `icon_что_то.png`.
3. В `ui.py` при создании кнопки укажите `icon="icon_что_то"`.

Если файла нет — нарисуется векторная заглушка, приложение не упадёт.

### Поменять шрифт

1. Положите TTF в `assets/fonts/`.
2. Откройте `fonts.py`, поправьте `FAMILY` и имена в `FILES`.
3. **Проверьте, что шрифт содержит кириллицу** — иначе русский текст подставится из другого шрифта.

## 🧪 Тесты

```bash
python test_core.py
```

```
Пройдено: 123   Провалено: 0
```

Тесты проверяют логику без интерфейса: разбор дат, шаблоны, дедупликацию имён, откат.
**Запускайте перед каждым коммитом** — они ловят регрессии за секунды.

Тесты учитывают платформу: проверки `.exe`/`.dll` выполняются только на Windows,
проверка `ctime` — только там, где система хранит дату создания. На другой ОС
эти проверки пропускаются, а не падают.

### Диагностика конкретного файла

```bash
python check_date.py "D:\Test\1392373.jpg"     # Windows
python check_date.py ~/Pictures/IMG_4823.jpg   # Linux / macOS
python check_date.py ~/Pictures                # по всей папке
```

Покажет все даты-кандидаты, отметит выбранную и итоговое имя. **Ничего не меняет.**

## 🐛 Частые проблемы

<details>
<summary><b>Кнопки без иконок</b></summary>

Нет папки `assets/icons/` или файлов в ней. Скопируйте `assets` целиком рядом с программой.
Приложение работает и без иконок — рисует векторные заглушки.

</details>

<details>
<summary><b>Русский текст другим шрифтом</b></summary>

Шрифт в `assets/fonts/` не содержит кириллицы. Roboto содержит. Если меняли шрифт —
проверьте набор глифов.

На macOS шрифт копируется в `~/Library/Fonts` и подхватывается **после перезапуска** —
при самом первом запуске возможен системный шрифт.

</details>

<details>
<summary><b>«В этой сборке Python нет tkinter»</b></summary>

**Windows:** переустановите Python с [python.org](https://python.org), отметив галочку
**«tcl/tk and IDLE»**.

**Linux:** `sudo apt install python3-tk`

**macOS:** `brew install python-tk`

</details>

<details>
<summary><b>Файлы пропущены с пометкой «дата недостоверна»</b></summary>

Программа нашла дату, но она выглядит подозрительно: из будущего, 1970 год или раньше 1990.
Такие файлы не трогаются намеренно. Проверьте: `python check_date.py "путь/к/файлу"`.

</details>

<details>
<summary><b>Не могу отменить операцию</b></summary>

Откат работает через журнал в папке `journal/`. Если её удалили — откатить нельзя.
Журналы хранят последние 20 сессий, старые чистятся автоматически.

</details>

<details>
<summary><b>Файл занят другой программой</b></summary>

На экране результата нажмите **«Повторить пропущенные»** после того, как закроете программу,
которая держит файл.

</details>

<details>
<summary><b>Linux: не работает перетаскивание папки</b></summary>

`tkinterdnd2` требует рабочего графического сеанса. Пользуйтесь кнопкой **«Выберите папку»** —
она работает всегда.

</details>
