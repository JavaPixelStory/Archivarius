# 📚 Архивариус

> **Наводит порядок в папке с файлами: раскладывает их по годам и переименовывает на основе даты создания — или раскладывает, сохраняя прежние имена.**

Без установки. Работает офлайн, никуда не отправляет данные.

[![Версия](https://img.shields.io/badge/версия-1.3-2F7D32?style=flat-square)](version.py)
[![Python](https://img.shields.io/badge/Python-3.11%2B-3776AB?style=flat-square&logo=python&logoColor=white)](https://python.org)
[![Платформа](https://img.shields.io/badge/платформа-Windows-0078D4?style=flat-square&logo=windows&logoColor=white)](#-системные-требования)

## 🤔 Зачем это нужно

У вас есть папка `Загрузки` или `Фото с телефона`, в которой лежат сотни файлов с именами вроде
`IMG_4823.jpg`, `23C8hcgG08k.jpg`, `korg-ax1500g-489958.jpg`. Найти что-то невозможно.

**Архивариус** превращает это в:

```
Было:                           Стало:
📁 Фото с телефона             📁 Фото с телефона
   IMG_4823.jpg          →        📁 2012
   23C8hcgG08k.jpg       →          📁 01-(можно добавить название)
   korg-ax1500g-489958.jpg →          📄 2012-01-24_21-00-42.jpg
   photo_2021.jpg        →        📁 2021
                                    📁 08-(можно добавить название)
                                      📄 2021-08-03_09-15-00.jpg
```

Не хотите терять исходные имена? Включите **«Раскладывать без переименования»** — файлы
переедут в те же папки годов и месяцев, но останутся `IMG_4823.jpg`:

```
Было:                           Стало:
📁 Фото с телефона             📁 Фото с телефона
   IMG_4823.jpg          →        📁 2012
   photo_2021.jpg        →          📁 01
                                      📄 IMG_4823.jpg
                                    📁 2021
                                      📁 08
                                        📄 photo_2021.jpg
```

В обоих режимах дата берётся не из имени файла, а **из самого файла**: EXIF-теги фотографий,
метаданные PDF и офисных документов, теги видео. Имя файла и дата изменения — только запасные
варианты.

### 🛡️ Безопасность

| Обещание             | Как выполнено                                                             |
| -------------------- | ------------------------------------------------------------------------- |
| Не удаляет файлы     | Только перенос, а в обычном режиме ещё и переименование                   |
| Не меняет содержимое | Файл не открывается на запись                                             |
| Не перезаписывает    | При совпадении имён добавляется `_2`, `_3`                                |
| Всё можно отменить   | Каждая операция пишется в журнал, откат одной кнопкой                     |
| Не лезет в сеть      | Ни одного сетевого запроса                                                |

## 🚀 Быстрый старт

### Вариант 1 — готовый `.exe` (для пользователей)

1. Скачайте `Archivarius.zip` со страницы [Releases](https://github.com/JavaPixelStory/Archivarius/tree/main/releases).
2. Распакуйте архив в любую папку.
3. Запустите двойным щелчком `Archivarius.exe`.

```
📁 Archivarius/
   ├── 📄 Archivarius.exe
   └── 📁 assets/          ← обязательно рядом с exe
```

> [!IMPORTANT]
> Установка не нужна, но папку `assets` удалять нельзя — приложение ищет в ней шрифт,
> иконки и картинки.

### Вариант 2 — из исходников (для разработки)

```bash
# 1. Клонировать репозиторий
git clone https://github.com/JavaPixelStory/Archivarius.git
cd Archivarius

# 2. Создать виртуальное окружение (рекомендуется)
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux / macOS

# 3. Установить зависимости
python -m pip install -r requirements.txt

# 4. Запустить
python main.py
```

Открыть сразу нужную папку:

```bash
python main.py "C:\Photos"
```

## 📖 Как пользоваться

### 1️⃣ Выберите папку

На главном экране перетащите папку в пунктирную область или нажмите **«Выберите папку»**.
Недавние папки сохраняются в выпадающем списке.

### 2️⃣ Проверьте

Откроется таблица: что (старое название) чем (новое название) станет. Ничего ещё не изменено.

| Колонка           | Что показывает                               |
| ----------------- | -------------------------------------------- |
| **Имя сейчас**    | Текущее имя файла                            |
| **Имя после**     | Как будет называться                         |
| **Папка**         | В какую подпапку попадёт, например `2012/11` |
| **Источник даты** | Откуда взята дата                            |
| **Статус**        | К переименованию / без изменений / ошибка    |

Нажмите на строку — внизу справа появится пояснение, откуда взялась дата именно у этого файла.

Фильтры сверху переключают между «все», «к переименованию», «без изменений»,
«дата недостоверна» и «ошибки».

> [!NOTE]
> В режиме «без переименования» колонки «Имя сейчас» и «Имя после» совпадают — это нормально.
> Файлы всё равно переедут в папки годов и месяцев.

### 3️⃣ Запустите

Кнопка **«Навести порядок!»**.

### 4️⃣ Результат

Показано, сколько файлов разложено. Доступны:

- **Вернуться к работе** — продолжить работу в программе
- **Открыть папку** — посмотреть результат в проводнике
- **Отменить изменения** — вернуть всё как было (по журналу)

### ❓ Кнопка «i»

В левом верхнем углу главного экрана — справка о том, как программа работает: откуда берёт
дату, что произойдёт с папками, как отменить операцию, чего не трогает.

## ⚙️ Настройки

Экран **«Настройки»** (кнопка справа сверху).

### Шаблон имени файла

По умолчанию: `{YYYY}-{MM}-{DD}_{HH}-{mm}-{ss}`

| Переменная | Значение     | Пример |
| ---------- | ------------ | ------ |
| `{YYYY}`   | Год, 4 цифры | `2012` |
| `{YY}`     | Год, 2 цифры | `12`   |
| `{MM}`     | Месяц        | `11`   |
| `{DD}`     | День         | `16`   |
| `{HH}`     | Часы         | `16`   |
| `{mm}`     | Минуты       | `09`   |
| `{ss}`     | Секунды      | `52`   |

Можно добавлять свой текст: `{YYYY}.{MM}.{DD} отпуск` → `2012.11.16 отпуск.jpg`

### Раскладывать без переименования

**Галочка в разделе «Дополнительно».** Включает режим, в котором файлы переезжают в папки
годов и месяцев, но сохраняют исходные имена.

|                        | Обычный режим                          | Без переименования          |
| ---------------------- | -------------------------------------- | --------------------------- |
| **Имя файла**          | по шаблону даты                        | исходное                    |
| **Папки**              | по шаблону папки                       | по шаблону папки            |
| **`IMG_4823.jpg`**     | `2012/11/2012-11-16_16-09-52.jpg`      | `2012/11/IMG_4823.jpg`      |
| **Шаблон имени нужен** | да                                     | нет                         |

Когда включать:

- **Имена несут смысл.** `Договор с ООО Ромашка.pdf` полезнее, чем `2019-03-14_10-22-05.pdf`.
- **На файлы ссылаются другие программы.** Переименование ломает ссылки в проектах,
  медиатеках, базах.
- **Нужен только порядок в папках.** Разложить по годам — да, менять имена — нет.

Что важно знать:

- **Шаблон имени не требуется.** Когда режим включён, поле шаблона можно оставить пустым —
  кнопка «Сохранить» останется активной.
- **Совпадения имён не перезаписываются.** Если два файла с одинаковым именем попадают в одну
  папку, второй получит суффикс: `photo.jpg` → `photo_2.jpg` → `photo_2_2.jpg`. То есть режим
  «без переименования» не абсолютен — при конфликте имя всё же меняется, иначе файл был бы
  потерян.
- **Повторный запуск ничего не делает.** Файл, который уже лежит в своей папке под своим
  именем, получает статус «без изменений».
- **Шаблон папки работает как обычно.** `{YYYY}`, `{YYYY}/{MM}`, `Архив {YYYY}/{MM}` — всё
  применимо.

> [!TIP]
> Сначала попробуйте режим **«Только отчёт»** вместе с этой галочкой: таблица покажет, в какие
> папки переедут файлы, и ничего не изменит.

### Шаблон папки года

Задаёт, как называются папки, в которые раскладываются файлы. По умолчанию: `{YYYY}/{MM}` — папка года, внутри неё папка месяца.

| Шаблон              | Структура                               | Когда использовать                       |
| ------------------- | --------------------------------------- | ---------------------------------------- |
| `{YYYY}`            | `2012/2012-11-16_16-09-52.jpg`          | Только по годам, без месяцев             |
| `{YYYY}/{MM}`       | `2012/11/2012-11-16_16-09-52.jpg`       | Год, внутри месяц цифрами (по умолчанию) |
| `{YYYY}/{MMM}`      | `2012/ноя/2012-11-16_16-09-52.jpg`      | Год, внутри месяц словами                |
| `Архив {YYYY}/{MM}` | `Архив 2012/11/2012-11-16_16-09-52.jpg` | Свой текст перед годом                   |

Правила: шаблон обязан содержать `{YYYY}` или `{YY}`, один `{MM}` не подходит. Части пути разделяются `/`; пустые части, обратный слэш и точка или пробел в конце части запрещены.

**Как переложить уже разложенные файлы.** Если вы меняете `{YYYY}` на `{YYYY}/{MM}`, файлы из `2012/` нужно перенести в `2012/11/`. Для этого включите опцию **«Включая вложенные папки»** — без неё программа видит только файлы в корне выбранной папки и ничего не переносит. Файлы, которые уже лежат на своих местах, при повторном запуске не трогаются.

**Настройка сохраняется.** Обновление программы не меняет ваш `settings.json`: если там уже записан `{YYYY}`, он останется. Чтобы перейти на `{YYYY}/{MM}`, выберите шаблон в настройках или нажмите «Сброс».

### Остальное

| Настройка                          | Что делает                                                        |
| ---------------------------------- | ----------------------------------------------------------------- |
| **Режим работы**                   | «Переименовать и разложить» или «Только отчёт, ничего не менять»  |
| **Раскладывать без переименования** | Переносить файлы по папкам, сохраняя исходные имена              |
| **Включая вложенные папки**        | Обходить подпапки; нужна, чтобы переложить уже разложенные файлы  |
| **Брать дату из имени файла**      | Если других дат нет — попробовать распознать в имени              |
| **Пропускать системные и скрытые** | Не трогать `desktop.ini`, `thumbs.db`, `.DS_Store`, скрытые файлы |

> [!TIP]
> Перед первой серьёзной операцией включите режим **«Только отчёт»** — он покажет план,
> но ничего не изменит.

## 🔧 Устройство кода

Проект разделён по ответственности — каждый файл можно читать отдельно.

### `core.py` — мозг приложения

Ничего не знает про интерфейс. Здесь всё про файлы и даты.

```python
core.plan(folder, cfg, cancel, progress)   # построить план, ничего не меняя
core.execute(folder, plan, cfg, journal)   # выполнить план
core.rollback(journal_path)                # отменить по журналу
core.detect_date(path, stat, cfg)          # определить дату файла
core.validate_template(template)           # проверить шаблон
```

Главный принцип: **`plan()` сначала строит полный план, `execute()` потом его выполняет.**
Поэтому вы всегда видите, что произойдёт, до того как это произойдёт.

Режим «без переименования» — это одна ветка внутри `plan()`:

```python
if cfg.get("keep_names"):
    dst_name = path.name        # имя остаётся прежним
else:
    dst_name = render_name(template, dt, path.stem, path.suffix.lstrip("."), counter)
```

Проверка «файл уже на месте» тоже учитывает режим — в `is_already_placed()` при
`keep_names` сверяется только папка, имя не проверяется.

### `ui.py` — экраны

Шесть экранов, каждый в своей функции:

| Функция           | Экран               |
| ----------------- | ------------------- |
| `_build_home`     | Главный             |
| `_build_preview`  | Просмотр с таблицей |
| `_build_progress` | Прогресс            |
| `_build_result`   | Результат           |
| `_build_journal`  | Журнал операций     |
| `_build_settings` | Настройки           |

Плюс `_open_help` — отдельное окно справки, открывается кнопкой «i» с главного экрана.

### `widgets.py` — внешний вид

Tkinter не умеет скруглять углы, поэтому кнопки и поля рисуются на Canvas:

- `RoundButton` — кнопка со скруглением, иконкой и подсветкой при наведении
- `Field` — поле ввода на зелёной подложке
- `CheckSquare`, `RadioDot` — флажки и переключатели (рисуются через Pillow, чтобы не были пиксельными)
- `DropZone` — зона перетаскивания с пунктиром
- `load_badge` — значок на зелёной подложке для заголовков справки

### `settings.py` — состояние

Хранит `settings.json` рядом с приложением. Журналы — в `journal/` рядом с ним же.

Если папка с программой защищена от записи (например, `Program Files`), настройки и журналы
уходят в `%LOCALAPPDATA%\Archivarius`.

## ✏️ Как вносить изменения

### Изменить внешний вид

Полная шпаргалка — в **[STYLE_GUIDE.md](STYLE_GUIDE.md)**. Коротко:

| Что                     | Файл                       |
| ----------------------- | -------------------------- |
| Цвета                   | `widgets.py` **и** `ui.py` |
| Радиусы кнопок          | `widgets.py`               |
| Отступы главного экрана | `ui.py`                    |
| Отступы в настройках    | `ui.py`                    |
| Шрифт                   | `fonts.py`                 |

> [!WARNING]
> Цвета продублированы в двух файлах. Меняйте **в обоих**, иначе кнопки и текстовые метки
> будут разного цвета.

### Изменить логику определения даты

1. Откройте `core.py`, найдите `metadata_date()`.
2. Добавьте обработку своего формата.
3. Проверьте результат: `python check_date.py "путь\к\файлу"`.
4. Запустите тесты: `python test_core.py`.

### Изменить шаблон по умолчанию

`settings.py`, словарь `DEFAULTS`:

```python
DEFAULTS = {
    "template": "{YYYY}-{MM}-{DD}_{HH}-{mm}-{ss}",
    "year_folder": "{YYYY}/{MM}",
    "keep_names": False,
    ...
}
```

`keep_names` — та самая галочка «Раскладывать без переименования». `False` — обычный режим
с переименованием, `True` — сохранять исходные имена.

## 📦 Сборка `.exe`

```bash
build.bat
```

Что происходит:

1. Проверка Python (нужен 3.11+)
2. Очистка `build/`, `dist/`, старого `.spec`
3. Запуск PyInstaller с `--onefile --windowed --icon assets/icon.ico`
4. Копирование `assets` в `dist/`
5. Итог: `dist\Archivarius.exe`

Если что-то пошло не так — скрипт назовёт шаг и покажет команду.

## 🐛 Частые проблемы

<details>
<summary><b>Кнопки без иконок</b></summary>

Нет папки `assets/icons/` или файлов в ней. Скопируйте `assets` целиком рядом с exe.
Приложение работает и без иконок — рисует векторные заглушки.

</details>

<details>
<summary><b>Русский текст другим шрифтом</b></summary>

Шрифт в `assets/fonts/` не содержит кириллицы. Roboto содержит. Если меняли шрифт —
проверьте набор глифов.

</details>

<details>
<summary><b>«В этой сборке Python нет tkinter»</b></summary>

Переустановите Python с [python.org](https://python.org), отметив галочку
**«tcl/tk and IDLE»** при установке.

</details>

<details>
<summary><b>Файлы пропущены с пометкой «дата недостоверна»</b></summary>

Программа нашла дату, но она выглядит подозрительно: из будущего, 1970 год или раньше 1990.
Такие файлы не трогаются намеренно. Проверьте: `python check_date.py "путь\к\файлу"`.

</details>

<details>
<summary><b>Включил «без переименования», а имя всё равно изменилось</b></summary>

Значит, в целевой папке уже был файл с таким именем. Второй получает суффикс `_2`,
третий `_2_2` — иначе один файл затёр бы другой. Это единственный случай, когда режим
меняет имя.

</details>

<details>
<summary><b>«Сохранить» неактивна при пустом шаблоне имени</b></summary>

Либо не включена галочка «Раскладывать без переименования» — тогда шаблон обязателен, —
либо включена, но пуст шаблон папки. Второй шаблон нужен всегда.

</details>

<details>
<summary><b>Не могу отменить операцию</b></summary>

Откат работает через журнал в папке `journal/`. Если её удалили — откатить нельзя.
Журналы хранят последние 20 сессий, старые чистятся автоматически.

</details>

<details>
<summary><b>Файл занят другой программой</b></summary>

На экране результата нажмите **«Повторить пропущенные»** после того, как закроете программу,
которая держит файл.

</details>
